使用说明

无需后端，直接前端在线编辑
1. 点击资源卡片可直接访问。
2. 点击“新增资源”可在线添加。
3. 每个资源支持“编辑 / 删除 / 复制链接”。
4. 分类支持“新增 / 重命名 / 删除”。
5. 分类和资源都支持拖拽排序。
6. 数据自动保存到本地浏览器。
7. 支持导出 JSON 备份与导入恢复。
8. Ctrl/Cmd + K 打开顶部搜索弹层。
